Potencias y raíces: propiedades y ejemplos

Elevar un número a una potencia es multiplicarlo por sí mismo varias veces, y la raíz es la operación inversa. Conocer sus propiedades permite simplificar cuentas y resolver ecuaciones sin calculadora.

Respuesta rápida

aᵐ·aⁿ = aᵐ⁺ⁿ · aᵐ/aⁿ = aᵐ⁻ⁿ · (aᵐ)ⁿ = aᵐ·ⁿ · a⁻ⁿ = 1/aⁿ · a^(1/n) = ⁿ√a.

Abrir calculadora

1. Qué es una potencia

aⁿ = a · a · … · a    (n veces)

En aⁿ, a es la base y n el exponente. 2⁵ = 2·2·2·2·2 = 32. Con exponente 0 el resultado siempre es 1 (a⁰ = 1, si a ≠ 0).

2. Propiedades de las potencias

PropiedadFórmulaEjemplo
Producto de igual baseaᵐ · aⁿ = aᵐ⁺ⁿ2³ · 2⁴ = 2⁷ = 128
Cociente de igual baseaᵐ / aⁿ = aᵐ⁻ⁿ5⁶ / 5⁴ = 5² = 25
Potencia de una potencia(aᵐ)ⁿ = aᵐ·ⁿ(3²)³ = 3⁶ = 729
Potencia de un producto(a·b)ⁿ = aⁿ · bⁿ(2·5)² = 4 · 25 = 100
Exponente negativoa⁻ⁿ = 1 / aⁿ5⁻² = 1/25 = 0,04

3. Exponentes fraccionarios

ap/q = q√(aᵖ)

Un exponente fraccionario es una raíz: el denominador es el índice y el numerador, la potencia.

  1. 9^(1/2) = √9 = 3
  2. 8^(2/3) = (∛8)² = 2² = 4
  3. 16^(3/4) = (⁴√16)³ = 2³ = 8

4. Qué es una raíz

ⁿ√x = y   ⇔   yⁿ = x

La raíz cuadrada de 49 es 7 porque 7² = 49. La raíz cúbica de −27 es −3, porque (−3)³ = −27: las raíces de índice impar existen para números negativos, pero las de índice par no (en los números reales).

5. Simplificar radicales

Se factoriza el número y se sacan de la raíz los factores que se repiten tantas veces como el índice.

  1. √72: 72 = 2³ · 3² = 2² · 3² · 2
  2. √72 = √(2² · 3²) · √2 = 2 · 3 · √2
  3. = 6√2 ≈ 8,485
  1. √50 = √(5² · 2) = 5√2 ≈ 7,071
  2. ∛54 = ∛(3³ · 2) = 3∛2 ≈ 3,780

6. Errores comunes

  • √(a + b) no es √a + √b: √(9 + 16) = 5, pero √9 + √16 = 7.
  • (a + b)² no es a² + b²: (3 + 4)² = 49, no 25. Falta el término 2ab.
  • (−2)² = 4, pero −2² = −4: sin paréntesis, el signo menos se aplica después.
  • √(a²) = |a|, no siempre a: √((−3)²) = 3.

Preguntas frecuentes

¿Cómo se resuelve una potencia con exponente negativo?
Es la inversa de la potencia positiva: a⁻ⁿ = 1/aⁿ.
¿Qué significa un exponente fraccionario?
Una raíz: a^(1/2) es la raíz cuadrada y a^(2/3) es la raíz cúbica de a al cuadrado.
¿Cómo se simplifica una raíz?
Se factoriza el radicando y se sacan los factores que se repiten el índice de veces: √72 = 6√2.
¿Existe la raíz cuadrada de un número negativo?
No en los números reales; en los complejos se define con la unidad imaginaria i.
