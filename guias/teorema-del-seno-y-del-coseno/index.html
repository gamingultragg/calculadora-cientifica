Teorema del seno y del coseno: cómo resolver triángulos

Pitágoras solo sirve en triángulos rectángulos. Para cualquier otro triángulo se usan los teoremas del seno y del coseno, que relacionan los lados con los ángulos.

Respuesta rápida

Coseno: c² = a² + b² − 2ab·cos(C). Seno: a/sen(A) = b/sen(B) = c/sen(C). Los ángulos suman 180°.

¿Preferís que lo calcule por vos?

Abrir calculadora

1. Los dos teoremas

c² = a² + b² − 2·a·b·cos(C)

a / sen(A) = b / sen(B) = c / sen(C)

El primero generaliza Pitágoras (si C = 90°, el coseno vale 0). El segundo relaciona cada lado con el seno de su ángulo opuesto.

2. Cuándo usar cada uno

DatosTeorema
Tres lados (LLL)Coseno, para hallar cada ángulo
Dos lados y el ángulo entre ellos (LAL)Coseno para el tercer lado; después seno o coseno
Dos ángulos y un lado (ALA / AAL)Seno (el tercer ángulo es 180° − A − B)

3. Ejemplo LAL

  1. a = 5, b = 7 y C = 60°
  2. c² = 25 + 49 − 2·5·7·cos 60° = 74 − 35 = 39 → c = 6,245
  3. cos A = (49 + 39 − 25) / (2·7·6,245) = 0,7206 → A = 43,9°
  4. B = 180° − 60° − 43,9° = 76,1°

4. Ejemplo ALA

  1. A = 40°, B = 60° y el lado c = 10 entre ellos
  2. C = 180° − 40° − 60° = 80°
  3. a = 10·sen 40° / sen 80° = 6,527
  4. b = 10·sen 60° / sen 80° = 8,794

5. El área

Con dos lados y el ángulo entre ellos: ½·a·b·sen(C). Con los tres lados, la fórmula de Herón: √(s(s−a)(s−b)(s−c)) con s = (a+b+c)/2.

6. Cuidado con el caso ambiguo

Con dos lados y un ángulo no comprendido (LLA) puede haber dos triángulos, uno o ninguno. Esta calculadora trabaja con los casos de solución única.

Preguntas frecuentes

¿Cuándo se usa el teorema del coseno?
Con tres lados, o con dos lados y el ángulo comprendido.
¿Cuándo se usa el teorema del seno?
Con dos ángulos y un lado.
¿Cuánto suman los ángulos de un triángulo?
180°.
¿Cómo se calcula el área sin la altura?
Con ½·a·b·sen(C) o con la fórmula de Herón.
