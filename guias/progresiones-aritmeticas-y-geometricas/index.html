Progresiones aritméticas y geométricas: fórmulas y ejemplos

Una progresión es una lista de números con una regla fija para pasar de uno al siguiente: sumar siempre lo mismo (aritmética) o multiplicar siempre por lo mismo (geométrica).

Respuesta rápida

Aritmética: aₙ = a₁ + (n − 1)d y Sₙ = n(a₁ + aₙ)/2. Geométrica: aₙ = a₁·r^(n−1) y Sₙ = a₁(rⁿ − 1)/(r − 1).

Abrir calculadora

1. Progresión aritmética

aₙ = a₁ + (n − 1)·d

  1. 3, 7, 11, 15… tiene a₁ = 3 y d = 4
  2. a₁₀ = 3 + 9 × 4 = 39
  3. S₁₀ = 10 × (3 + 39) / 2 = 210

Gauss resolvió de chico la suma 1 + 2 + … + 100 con esta idea: 100 × 101 / 2 = 5050.

2. Progresión geométrica

aₙ = a₁ · rn−1

  1. 2, 6, 18, 54, 162… tiene a₁ = 2 y r = 3
  2. a₅ = 2 × 3⁴ = 162
  3. S₅ = 2 × (3⁵ − 1) / (3 − 1) = 242

3. Suma de infinitos términos

S∞ = a₁ / (1 − r), si |r| < 1

1 + ½ + ¼ + ⅛ + … = 1 / (1 − ½) = 2. Si |r| ≥ 1, los términos no se achican y la suma no converge.

4. Cómo distinguirlas

  • Restá términos consecutivos: si la diferencia es siempre la misma, es aritmética.
  • Dividí términos consecutivos: si el cociente es siempre el mismo, es geométrica.

5. Aplicaciones

  • Ahorro que aumenta $1.000 por mes desde $10.000: en 12 meses ahorrás 12 × (10.000 + 21.000) / 2 = $186.000 (aritmética).
  • Interés compuesto y crecimiento de poblaciones: son progresiones geométricas.
  • Rebote de una pelota que sube cada vez a una fracción de la altura anterior: geométrica con r < 1.

Preguntas frecuentes

¿Cómo se calcula el término n de una progresión aritmética?
aₙ = a₁ + (n − 1)·d.
¿Cómo se suma una progresión aritmética?
Sₙ = n·(a₁ + aₙ)/2.
¿Cómo se calcula una progresión geométrica?
aₙ = a₁·r^(n−1); la suma es a₁(rⁿ − 1)/(r − 1).
¿Cuándo converge la suma infinita?
Cuando |r| < 1: S∞ = a₁/(1 − r).
