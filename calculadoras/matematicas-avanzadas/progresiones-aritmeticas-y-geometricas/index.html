Ayuda y Fórmulas Teóricas

Progresión aritmética

aₙ = a₁ + (n − 1)·d  ·  Sₙ = n·(a₁ + aₙ) / 2

Cada término se obtiene sumando una diferencia constante d. Ejemplo: 3, 7, 11, 15… tiene d = 4.

Progresión geométrica

aₙ = a₁·r^(n−1)  ·  Sₙ = a₁·(rⁿ − 1) / (r − 1)

Cada término se obtiene multiplicando por una razón constante r. Ejemplo: 2, 6, 18, 54… tiene r = 3. Si r = 1, la suma es n·a₁.

Suma infinita

S∞ = a₁ / (1 − r), con |r| < 1

Si la razón está entre −1 y 1, los términos se achican y la suma de infinitos términos converge. Con a₁ = 1 y r = ½, S∞ = 2.

Preguntas frecuentes

¿Cómo se calcula el término n de una progresión aritmética?
aₙ = a₁ + (n − 1)·d. Para 3, 7, 11…: el décimo término es 3 + 9 × 4 = 39.
¿Cómo se suman los términos de una progresión aritmética?
Sₙ = n·(a₁ + aₙ)/2. Los diez primeros de 3, 7, 11… suman 10 × (3 + 39) / 2 = 210.
¿Cómo se calcula el término n de una progresión geométrica?
aₙ = a₁·r^(n−1). Para 2, 6, 18…: el quinto término es 2 × 3⁴ = 162.
¿Cuándo converge la suma de una progresión geométrica?
Cuando |r| < 1: S∞ = a₁/(1 − r). Con a₁ = 1 y r = 1/2 da 2.
¿Cómo distingo si es aritmética o geométrica?
Si la diferencia entre términos consecutivos es constante, es aritmética; si lo es el cociente, es geométrica.
