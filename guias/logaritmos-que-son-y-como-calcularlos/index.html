Logaritmos: qué son y cómo calcularlos

El logaritmo es la operación inversa de la potencia: responde a la pregunta "¿a qué exponente hay que elevar esta base para obtener este número?". Aparece en el pH, los decibeles y el interés compuesto.

Respuesta rápida

log_b(x) = y ⇔ bʸ = x · log_b(x) = ln(x)/ln(b) · log(a·b) = log a + log b.

¿Preferís que lo calcule por vos?

Abrir calculadora

1. Qué es un logaritmo

log_b(x) = y   ⇔   bʸ = x

Si 2³ = 8, entonces log₂(8) = 3. El logaritmo de un número en cierta base es el exponente al que hay que elevar esa base para obtener el número.

PotenciaLogaritmo
10³ = 1.000log₁₀(1.000) = 3
2⁵ = 32log₂(32) = 5
3⁴ = 81log₃(81) = 4
5⁻¹ = 0,2log₅(0,2) = −1

2. log, ln y log₂

  • log (o log₁₀): logaritmo decimal, de base 10.
  • ln: logaritmo natural, de base e ≈ 2,71828.
  • log₂: logaritmo binario, de base 2 (informática).

Se relacionan por una constante: ln(x) ≈ 2,3026 · log(x).

3. Cambio de base

Las calculadoras traen solo las teclas log y ln, pero cualquier logaritmo se calcula con ellas:

log_b(x) = ln(x) / ln(b)

  1. log₃(81)
  2. ln(81) / ln(3) = 4,3944 / 1,0986
  3. = 4

4. Propiedades

  • log(a·b) = log(a) + log(b)
  • log(a/b) = log(a) − log(b)
  • log(aⁿ) = n·log(a)
  • log_b(1) = 0 y log_b(b) = 1

5. Resolver una ecuación exponencial

Para despejar un exponente, se aplica logaritmo a ambos lados.

  1. 2ˣ = 20
  2. x = log₂(20) = ln(20) / ln(2)
  3. x = 2,9957 / 0,6931 ≈ 4,32
  1. ¿En cuántos años se duplica un capital al 5 % anual?
  2. 1,05ⁿ = 2 → n = ln(2) / ln(1,05)
  3. n = 0,6931 / 0,0488 ≈ 14,2 años

6. Para qué se usan

  • pH = −log[H⁺]: la acidez en química.
  • Decibeles: la intensidad del sonido.
  • Escala de Richter: la magnitud de los sismos.
  • Interés compuesto y crecimiento exponencial.

7. Errores comunes

  • Creer que log(a + b) = log(a) + log(b): no es cierto, esa propiedad vale para el producto.
  • Calcular el logaritmo de 0 o de un número negativo: no existe en los reales.
  • Usar la base 1: no sirve, porque 1 elevado a cualquier número da 1.

Preguntas frecuentes

¿Qué es un logaritmo?
Es el exponente al que hay que elevar una base para obtener un número: log₁₀(1.000) = 3 porque 10³ = 1.000.
¿Cómo se calcula un logaritmo en base 2 con una calculadora común?
Con el cambio de base: log₂(x) = ln(x)/ln(2) (o log(x)/log(2)).
¿Qué diferencia hay entre log y ln?
log es el logaritmo decimal (base 10) y ln es el natural (base e).
¿Por qué no existe el logaritmo de un número negativo?
Porque una base positiva elevada a cualquier exponente real nunca da un resultado negativo ni cero.
