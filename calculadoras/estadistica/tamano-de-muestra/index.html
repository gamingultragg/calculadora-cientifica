Ayuda y Fórmulas Teóricas

La fórmula

n₀ = z² · p · (1 − p) / e²

z es el valor crítico del nivel de confianza (1,96 para 95 %), p la proporción esperada y e el margen de error. Con p = 50 %, z = 1,96 y e = 5 %: n₀ = 385.

Población finita

n = n₀ / (1 + (n₀ − 1) / N)

Si la población N es chica, la muestra necesaria baja: con N = 1.000 y los datos anteriores, n = 278.

Qué es cada dato

El margen de error es cuánto puede alejarse tu estimación del valor real; el nivel de confianza, qué tan seguro querés estar de que el valor real cae dentro de ese margen.

Preguntas frecuentes

¿Cómo se calcula el tamaño de la muestra?
n = z²·p·(1 − p)/e². Con 95 % de confianza, p = 50 % y error 5 %: 385 personas.
¿Qué proporción uso si no la conozco?
50 %: es la que maximiza p·(1 − p) y da la muestra más grande, o sea, la opción segura.
¿Influye el tamaño de la población?
Solo si la población es chica: se aplica la corrección por población finita. Para poblaciones grandes, casi no cambia.
¿Cómo reduzco el tamaño de la muestra?
Aceptando un margen de error mayor o un nivel de confianza menor.
¿Sirve para estimar medias?
Esta calculadora es para proporciones. Para medias se usa n = (z·σ/e)².
