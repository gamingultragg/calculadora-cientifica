Cómo calcular el tamaño de una muestra

Antes de hacer una encuesta hay que decidir a cuántas personas preguntar: pocas dan resultados poco confiables y muchas encarecen el estudio. La fórmula para proporciones lo resuelve.

Respuesta rápida

n = z²·p·(1 − p) / e². Con 95 % de confianza, p = 50 % y error de 5 % hacen falta 385 personas.

¿Preferís que lo calcule por vos?

Abrir calculadora

1. La fórmula

n₀ = z² · p · (1 − p) / e²

  • z: valor crítico del nivel de confianza (1,645, 1,96 o 2,576).
  • p: proporción esperada; si no la conocés, 0,5 (la peor situación, que da la muestra más grande).
  • e: margen de error (por ejemplo 0,05).
  1. 95 % de confianza (z = 1,96), p = 0,5, e = 0,05
  2. n₀ = 1,96² × 0,5 × 0,5 / 0,05² = 384,16
  3. Se redondea hacia arriba: 385 personas

2. Población finita

n = n₀ / (1 + (n₀ − 1) / N)

Si la población es chica, la muestra necesaria baja. Para N = 1.000: n = 385 / (1 + 384/1000) = 278.

4. Cómo bajar el tamaño de la muestra

  • Aceptar un margen de error mayor (duplicarlo divide la muestra por cuatro).
  • Bajar la confianza.
  • Si tenés una estimación previa de p lejos del 50 %, usarla.

5. Para estimar una media

La fórmula es n = (z·σ/e)², donde σ es el desvío estándar de la población y e el error absoluto aceptado. Esta guía y la calculadora tratan proporciones.

6. Errores comunes

  • Creer que la muestra debe ser un porcentaje de la población: lo que importa es el tamaño absoluto.
  • Olvidar que una muestra grande no corrige un muestreo sesgado.
  • No redondear hacia arriba.

Preguntas frecuentes

¿Cómo se calcula el tamaño de la muestra?
n = z²·p·(1 − p)/e².
¿Cuántas personas hay que encuestar con 95 % y 5 %?
385.
¿Qué proporción uso si no la conozco?
50 %.
¿Influye el tamaño de la población?
Solo si es chica: se aplica la corrección por población finita.
