Ayuda y Fórmulas Teóricas

Las letras

I = 1 · V = 5 · X = 10 · L = 50 · C = 100 · D = 500 · M = 1000.

Reglas de escritura

Las letras se suman de mayor a menor (XVI = 16). Una letra menor delante de una mayor se resta (IV = 4, IX = 9, XL = 40, XC = 90, CD = 400, CM = 900). I, X, C y M se repiten hasta tres veces seguidas; V, L y D no se repiten.

Límite

El sistema estándar llega hasta 3999 (MMMCMXCIX): para números mayores se usaba una barra sobre la letra, que multiplica por mil.

Preguntas frecuentes

¿Cómo se escribe 2024 en números romanos?
MMXXIV: MM (2000) + XX (20) + IV (4).
¿Cómo se convierte un número romano a arábigo?
Se suman los valores de las letras, restando los de las que están delante de una mayor. MCMXCIV = 1000 + 900 + 90 + 4 = 1994.
¿Cuál es el número romano más grande?
En el sistema estándar, 3999 (MMMCMXCIX).
¿Por qué IIII no es válido?
La regla estándar pide escribir 4 como IV (aunque algunos relojes usan IIII por tradición).
¿Existe el cero en números romanos?
No: los romanos no tenían símbolo para el cero.
