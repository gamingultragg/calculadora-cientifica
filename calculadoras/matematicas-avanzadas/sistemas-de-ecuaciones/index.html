Ayuda y Fórmulas Teóricas

Regla de Cramer

x = Δₓ / Δ  ·  y = Δᵧ / Δ  ·  z = Δ_z / Δ

Δ es el determinante de la matriz de coeficientes y Δₓ, Δᵧ, Δ_z son los determinantes que resultan de reemplazar la columna de x, y o z por los términos independientes.

Sistema 2×2

Δ = a₁·b₂ − a₂·b₁

Si Δ ≠ 0 hay una única solución. Si Δ = 0, el sistema es incompatible (sin solución) o compatible indeterminado (infinitas soluciones).

Verificación

Reemplazá los valores obtenidos en cada ecuación: tienen que dar el término independiente. La calculadora lo muestra en el sistema 2×2.

Preguntas frecuentes

¿Cómo se resuelve un sistema de ecuaciones 2×2?
Con sustitución, igualación, reducción o la regla de Cramer: x = Δₓ/Δ e y = Δᵧ/Δ, con Δ = a₁b₂ − a₂b₁. Para 2x + y = 5 y x − y = 1: Δ = −3, x = 2, y = 1.
¿Qué pasa si el determinante es 0?
El sistema no tiene solución única: puede ser incompatible (rectas paralelas) o tener infinitas soluciones (ecuaciones equivalentes).
¿Cómo se resuelve un sistema 3×3?
Con la regla de Cramer (cuatro determinantes de 3×3), el método de Gauss o sustitución sucesiva.
¿Y si una ecuación no tiene una de las incógnitas?
Su coeficiente vale 0: dejá el campo vacío.
¿Sirve para sistemas no lineales?
No: solo para ecuaciones lineales (sin potencias ni productos de incógnitas).
