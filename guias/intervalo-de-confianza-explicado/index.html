El intervalo de confianza explicado paso a paso

Una media calculada con una muestra casi nunca coincide con la de toda la población. El intervalo de confianza da un rango razonable donde está la media verdadera.

Respuesta rápida

x̄ ± c · s/√n, con c = z (normal) o t de Student si el desvío es muestral y n ≤ 30. Al 95 %, z = 1,96.

¿Preferís que lo calcule por vos?

Abrir calculadora

1. La fórmula

x̄ ± c · s / √n

x̄ es la media de la muestra, s el desvío, n el tamaño y c el valor crítico del nivel de confianza. A s/√n se lo llama error estándar.

2. z o t

Confianzazt (n = 25)
90 %1,6451,711
95 %1,9602,064

Se usa z si el desvío poblacional es conocido o la muestra es grande (n > 30). Con muestras chicas y desvío muestral se usa t de Student, que da intervalos algo más anchos.

3. Ejemplo con muestra grande

  1. Media 50, desvío 10, n = 100, confianza 95 %
  2. Error estándar = 10 / √100 = 1
  3. Margen = 1,96 × 1 = 1,96
  4. Intervalo: [48,04 ; 51,96]

4. Ejemplo con muestra chica

  1. Media 50, desvío muestral 10, n = 25, confianza 95 %
  2. t con 24 grados de libertad = 2,064
  3. Margen = 2,064 × 10 / 5 = 4,13
  4. Intervalo: [45,87 ; 54,13]

5. Cómo interpretarlo

"Con 95 % de confianza, la media está entre 48,04 y 51,96" significa que el método usado captura la media verdadera en el 95 % de las muestras. No es la probabilidad de que esta media en particular esté ahí.

6. Cómo achicar el intervalo

  • Aumentar el tamaño de la muestra (el margen baja con la raíz de n).
  • Bajar el nivel de confianza (a costa de menos seguridad).
  • Tener menos variabilidad en los datos.

Preguntas frecuentes

¿Cómo se calcula el intervalo de confianza?
x̄ ± c·s/√n.
¿Cuándo uso t de Student?
Con desvío muestral y n ≤ 30.
¿Qué es el margen de error?
c·s/√n: la mitad del ancho del intervalo.
¿Cómo lo interpreto?
Es el rango donde, con el nivel de confianza elegido, está la media verdadera.
