Cómo graficar una función paso a paso

Un gráfico muestra de un vistazo lo que una fórmula esconde: dónde sube, dónde baja y dónde corta los ejes. Esta guía explica los tipos de función, los puntos que conviene buscar y cómo interpretar la curva.

Respuesta rápida

Buscá la ordenada al origen f(0), los ceros (f(x) = 0), el vértice si es una parábola (x = −b/2a) y las asíntotas. Con esos puntos se esboza cualquier curva.

1. Qué es graficar una función

Graficar f(x) es dibujar todos los puntos (x, f(x)). Cada valor de x en el eje horizontal se asocia con su resultado en el eje vertical. La curva resultante muestra de un vistazo dónde crece, dónde decrece, dónde corta los ejes y qué valores alcanza.

2. Los tipos de función más comunes

Linealf(x) = m·x + bUna recta: m es la pendiente y b la ordenada al origen
Cuadráticaf(x) = a·x² + b·x + cUna parábola con vértice; abre hacia arriba si a > 0

3. Cómo encontrar los puntos importantes

  • Ordenada al origen: el punto donde corta el eje y: se calcula f(0). Para x² − 4 es −4.
  • Ceros o raíces: donde corta el eje x: se resuelve f(x) = 0. Para x² − 4 = 0, x = −2 y x = 2.
  • Vértice de una parábola: en x = −b / (2a). Para x² − 4 está en x = 0, con y = −4 (el mínimo).
  • Asíntotas: rectas a las que la curva se acerca sin tocarlas; en 1/x son los ejes.

4. Ejemplo: x² − 4

  1. Es una parábola (a = 1 > 0): abre hacia arriba
  2. Vértice: x = −b/(2a) = 0 → y = −4
  3. Ceros: x² = 4 → x = ±2
  4. Ordenada al origen: f(0) = −4

5. Comparar dos funciones

Para saber dónde se cortan f(x) = x² y g(x) = 2x + 3 se grafican juntas y se miran los puntos de cruce; algebraicamente se resuelve x² = 2x + 3, o sea x² − 2x − 3 = 0, con soluciones x = −1 y x = 3.

6. Cómo leer un gráfico

  • Donde la curva sube de izquierda a derecha, la función crece; donde baja, decrece.
  • Los máximos y mínimos son los puntos donde cambia de sentido.
  • Si la curva es simétrica respecto del eje y, la función es par (como x²); si lo es respecto del origen, es impar (como x³).
  • Los "saltos" indican discontinuidades: valores de x donde la función no está definida.

7. Errores comunes

  • Escribir 2x² como 2x^2 está bien, pero (2x)^2 es otra función: 4x².
  • Usar grados en lugar de radianes en las funciones trigonométricas.
  • Mirar un rango de x tan grande o tan chico que la forma de la curva se pierde: ajustá el zoom.
  • Olvidar el dominio: ln(x) y sqrt(x) no existen para ciertos valores.

Preguntas frecuentes

¿Cómo se grafica una función?
Se calculan varios puntos (x, f(x)) y se unen con una curva, marcando ceros, ordenada al origen, vértice y asíntotas.
¿Cómo se halla el vértice de una parábola?
En x = −b/(2a); el valor de y se obtiene evaluando la función en ese x.
¿Qué son los ceros de una función?
Los valores de x donde f(x) = 0: donde la curva corta el eje horizontal.
¿Qué es una asíntota?
Una recta a la que la curva se acerca indefinidamente sin tocarla, como los ejes en 1/x.
