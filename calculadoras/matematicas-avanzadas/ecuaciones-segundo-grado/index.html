a·x² + b·x + c = 0

    Ayuda y Fórmulas Teóricas

    Fórmula cuadrática

    x = (-b ± √(b² - 4ac)) / 2a

    El discriminante (Δ)

    Δ > 0: dos raíces reales distintas.

    Δ = 0: una raíz real doble.

    Δ < 0: dos raíces complejas conjugadas.

    ¿Por qué a no puede ser 0?

    Si a = 0 el término cuadrático desaparece y la ecuación se vuelve lineal (bx + c = 0), fuera del alcance de esta calculadora.
