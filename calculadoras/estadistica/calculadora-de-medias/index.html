Calculadora de Media Aritmética, Geométrica y Armónica

Pegá una lista de números y obtenés la media aritmética, la geométrica, la armónica y la cuadrática. Cada una sirve para un caso distinto: la geométrica para tasas de crecimiento, la armónica para velocidades y rendimientos.

Separalos con espacios, saltos de línea o punto y coma. Los decimales, con coma o con punto.

La media geométrica y la armónica solo se definen para números mayores que 0.

Ayuda y Fórmulas Teóricas

Media aritmética y cuadrática

AM = (x₁ + … + xₙ) / n  ·  QM = √((x₁² + … + xₙ²) / n)

La aritmética es el promedio de siempre. La cuadrática se usa en física e ingeniería (por ejemplo, el valor eficaz de una señal).

Media geométrica

GM = ⁿ√(x₁ · x₂ · … · xₙ)

Es la adecuada para promediar factores de crecimiento, razones y tasas que se acumulan: si algo crece 10 %, 20 % y baja 5 %, el crecimiento promedio por período es la media geométrica de 1,10, 1,20 y 0,95.

Media armónica

HM = n / (1/x₁ + … + 1/xₙ)

Es la correcta para promediar velocidades en tramos de igual distancia o rendimientos: ida a 60 km/h y vuelta a 40 km/h dan una velocidad media de 48 km/h, no de 50.

Preguntas frecuentes

¿Cuál es la diferencia entre la media aritmética y la geométrica?
La aritmética suma y divide; la geométrica multiplica y saca raíz. La geométrica es la adecuada para tasas de crecimiento y razones.
¿Cuándo se usa la media armónica?
Para promediar velocidades en tramos de igual distancia, precios por unidad o rendimientos. Ida a 60 km/h y vuelta a 40 km/h: 48 km/h.
¿Cómo se calcula el crecimiento promedio?
Con la media geométrica de los factores. Para +10 %, +20 % y −5 %: (1,10 × 1,20 × 0,95)^(1/3) ≈ 1,078, o sea un 7,8 % por período.
¿Qué relación hay entre las medias?
Para números positivos: armónica ≤ geométrica ≤ aritmética ≤ cuadrática, y son iguales solo si todos los datos coinciden.
¿Se pueden usar números negativos o ceros?
En la aritmética y la cuadrática sí; en la geométrica y la armónica no.
