Error absoluto, relativo y porcentual

Toda medición tiene un error. Saber cuánto vale y expresarlo bien es una parte central de cualquier informe de laboratorio, y se resuelve con tres fórmulas simples y una medida para series de datos.

Respuesta rápida

E = |medido − real| · e = E / |real| · e % = e × 100 · error estándar = s / √n.

¿Preferís que lo calcule por vos?

Abrir calculadora

1. Error absoluto, relativo y porcentual

E = |valor medido − valor real|   ·   e = E / |valor real|   ·   e % = e × 100

  • El error absoluto tiene las unidades de la medición y dice cuánto se erró.
  • El error relativo es un número sin unidades: permite comparar mediciones de distinta magnitud.
  • El error porcentual es el relativo expresado en %.
  1. Se mide la aceleración de la gravedad y da 9,65 m/s² (valor de referencia: 9,81)
  2. E = |9,65 − 9,81| = 0,16 m/s²
  3. e = 0,16 / 9,81 = 0,0163 → 1,63 %
  1. Se mide una pieza de 50 mm y la regla indica 49,2 mm
  2. E = 0,8 mm · e = 0,8 / 50 = 0,016 → 1,6 %

Un error de 1 cm es enorme si se mide un tornillo y despreciable si se mide una cancha: el relativo muestra la diferencia.

2. Exactitud y precisión

  • Exactitud: qué tan cerca está la medición del valor real (error pequeño).
  • Precisión: qué tan parecidas son entre sí las mediciones repetidas (poca dispersión).

Una balanza mal calibrada puede dar siempre el mismo valor equivocado: es muy precisa pero poco exacta.

3. Una serie de mediciones

Cuando se repite la medición, el mejor valor es el promedio, y su incertidumbre se estima con el error estándar:

x̄ = Σx / n   ·   s = √(Σ(x − x̄)² / (n − 1))   ·   error estándar = s / √n

  1. Cuatro mediciones de g: 9,80 · 9,70 · 9,90 · 9,75
  2. promedio = 9,7875
  3. s = 0,0854 · error estándar = 0,0854 / √4 = 0,0427
  4. resultado: g = 9,79 ± 0,04 m/s²

El error estándar baja con la raíz de la cantidad de mediciones: para reducirlo a la mitad hay que cuatro veces más datos.

4. Cómo se expresa el resultado

  • La incertidumbre se redondea a una o dos cifras significativas.
  • El valor se escribe con los mismos decimales que la incertidumbre: 9,79 ± 0,04, no 9,7875 ± 0,04.

5. Propagación de errores (reglas simples)

  • Suma y resta: se suman los errores absolutos.
  • Producto y cociente: se suman los errores relativos.
  1. Un rectángulo mide 20,0 ± 0,1 cm por 10,0 ± 0,1 cm
  2. errores relativos: 0,1/20 = 0,5 % y 0,1/10 = 1 % → suma 1,5 %
  3. área = 200 cm² ± 1,5 % = 200 ± 3 cm²

6. Errores comunes

  • Dividir por el valor medido en lugar del valor real.
  • Olvidar el valor absoluto y obtener un error negativo.
  • Informar demasiados decimales.
  • Confundir el desvío estándar (dispersión de los datos) con el error estándar (incertidumbre del promedio).

Ejercicios para practicar

Probá resolverlos vos y después abrí la solución para comparar.

  1. Una balanza marca 250 g para una pesa de 245 g. ¿Cuál es el error absoluto, relativo y porcentual?

    Ver la solución

    E = |250 − 245| = 5 g. e = 5 / 245 = 0,0204. Porcentual: 2,04 %.

  2. Se mide una mesa de 119,5 cm como 120,0 cm. ¿Cuál es el error porcentual?

    Ver la solución

    E = 0,5 cm. e = 0,5 / 119,5 = 0,00418 → 0,42 %.

  3. Cuatro mediciones de un tiempo dan 2,1 · 2,3 · 2,2 · 2,2 s. ¿Cómo se informa el resultado?

    Ver la solución

    Promedio = 2,2 s. s = 0,0816 y error estándar = 0,0816 / √4 = 0,0408. Resultado: 2,20 ± 0,04 s.

Preguntas frecuentes

¿Cómo se calcula el error absoluto?
Es el valor absoluto de la diferencia entre lo medido y el valor real.
¿Cómo se calcula el error porcentual?
Se divide el error absoluto por el valor real y se multiplica por 100.
¿Qué diferencia hay entre exactitud y precisión?
Exactitud: cercanía al valor real. Precisión: cercanía entre mediciones repetidas.
¿Qué es el error estándar de la media?
s/√n: la incertidumbre del promedio de una serie de mediciones.
