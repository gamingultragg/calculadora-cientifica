Cómo calcular el MCD y el MCM con ejemplos

El máximo común divisor y el mínimo común múltiplo aparecen cada vez que simplificás o sumás fracciones y en los problemas de coincidencia. Hay tres formas de calcularlos; esta guía las compara con el mismo ejemplo.

Respuesta rápida

MCD: factores primos comunes con el menor exponente. MCM: todos los factores primos con el mayor exponente. Atajo para dos números: MCM = (a × b) / MCD.

¿Preferís que lo calcule por vos?

Abrir calculadora

1. Qué son el MCD y el MCM

  • MCD (máximo común divisor): el mayor número que divide a todos los números dados. MCD(12, 18) = 6.
  • MCM (mínimo común múltiplo): el menor número positivo que es múltiplo de todos. MCM(12, 18) = 36.

2. Método 1: factores primos

Se descompone cada número en factores primos. Ejemplo con 360 y 84:

  1. 360 = 2³ × 3² × 5
  2. 84 = 2² × 3 × 7

MCD: factores comunes con el menor exponente → 2² × 3 = 12.

MCM: todos los factores con el mayor exponente → 2³ × 3² × 5 × 7 = 2.520.

3. Método 2: algoritmo de Euclides (para el MCD)

Se divide el mayor por el menor y se repite con el divisor y el resto, hasta que el resto sea 0. El último resto distinto de 0 es el MCD. Es el método más rápido con números grandes.

  1. 360 = 84 × 4 + 24
  2. 84 = 24 × 3 + 12
  3. 24 = 12 × 2 + 0 → MCD = 12

4. Atajo: del MCD al MCM

MCD(a, b) × MCM(a, b) = a × b

Con el MCD ya calculado, el MCM de dos números sale de la fórmula: MCM(360, 84) = 360 × 84 / 12 = 30.240 / 12 = 2.520. Con tres o más números, el atajo no se aplica directo: se calcula de a pares o con factores primos.

Ejemplo con tres números: 48, 180 y 24

  1. 48 = 2⁴ × 3
  2. 180 = 2² × 3² × 5
  3. 24 = 2³ × 3
  4. MCD = 2² × 3 = 12
  5. MCM = 2⁴ × 3² × 5 = 720

5. Para qué sirven

  • Simplificar fracciones (MCD): 180/48 → se divide arriba y abajo por 12 → 15/4.
  • Sumar fracciones (MCM): 1/12 + 1/18 → denominador común 36 → 3/36 + 2/36 = 5/36.
  • Problemas de coincidencia (MCM): si un colectivo pasa cada 12 minutos y otro cada 18, vuelven a coincidir cada 36 minutos.
  • Repartir en grupos iguales (MCD): 48 chicos y 180 libros se pueden repartir en 12 grupos iguales, cada uno con 4 chicos y 15 libros.

6. Errores comunes

  • Confundir MCD con MCM: el MCD nunca es mayor que el menor de los números, y el MCM nunca es menor que el mayor.
  • Tomar el exponente mayor para el MCD o el menor para el MCM (es al revés).
  • Olvidar los factores que no son comunes al calcular el MCM.

Preguntas frecuentes

¿Cómo se calcula el MCD?
Con factores primos (los comunes con el menor exponente) o con el algoritmo de Euclides: se divide el mayor por el menor y se repite con el resto hasta llegar a 0; el último resto distinto de 0 es el MCD.
¿Cómo se calcula el MCM?
Con factores primos (todos, con el mayor exponente) o como (a × b) / MCD para dos números.
¿Para qué sirve el MCD?
Para simplificar fracciones y repartir cosas en la mayor cantidad posible de grupos iguales.
¿Para qué sirve el MCM?
Para sumar y restar fracciones con distinto denominador y para resolver problemas de coincidencia de eventos periódicos.
