Ayuda y Fórmulas Teóricas

Teorema del coseno

c² = a² + b² − 2·a·b·cos(C)

Generaliza Pitágoras a cualquier triángulo. Con tres lados se despeja cada ángulo: cos(A) = (b² + c² − a²) / (2·b·c).

Teorema del seno

a / sen(A) = b / sen(B) = c / sen(C)

Relaciona cada lado con el seno de su ángulo opuesto. Sirve cuando se conocen dos ángulos y un lado.

Área

Área = √(s·(s−a)·(s−b)·(s−c)), con s = (a+b+c)/2

Fórmula de Herón. La suma de los ángulos interiores siempre es 180°.

Preguntas frecuentes

¿Cómo se resuelve un triángulo con tres lados?
Con el teorema del coseno se obtiene cada ángulo: cos(A) = (b² + c² − a²)/(2bc). Con lados 3, 4 y 5 el ángulo C es 90°.
¿Cuándo uso el teorema del seno?
Cuando conocés dos ángulos y un lado (o dos lados y un ángulo opuesto a uno de ellos).
¿Cuándo uso el teorema del coseno?
Cuando conocés tres lados, o dos lados y el ángulo comprendido entre ellos.
¿Cuánto suman los ángulos de un triángulo?
180°. Por eso, conocidos dos, el tercero es 180° − A − B.
¿Cómo calculo el área sin la altura?
Con la fórmula de Herón a partir de los tres lados, o con ½·a·b·sen(C).
