Ayuda y Fórmulas Teóricas

La fórmula

x̄ ± c · s/√n

x̄ es la media muestral, s el desvío, n el tamaño y c el valor crítico: z si el desvío poblacional es conocido o la muestra es grande (n > 30), y t de Student con n − 1 grados de libertad si el desvío es muestral y n ≤ 30.

Valores críticos z

90 % → 1,645 · 95 % → 1,960 · 99 % → 2,576.

Cómo se interpreta

Un intervalo del 95 % significa que, si repetiras el muestreo muchas veces, el 95 % de los intervalos construidos así contendrían a la media verdadera. No es la probabilidad de que la media esté dentro de este intervalo en particular.

Preguntas frecuentes

¿Cómo se calcula el intervalo de confianza de la media?
x̄ ± c·s/√n. Con media 50, desvío 10, n = 100 y 95 %: 50 ± 1,96 × 1 = [48,04 ; 51,96].
¿Cuándo uso t de Student y cuándo z?
z cuando el desvío poblacional es conocido o n > 30; t cuando solo tenés el desvío de la muestra y n ≤ 30.
¿Qué significa un nivel de confianza del 95 %?
Que el método usado captura la media verdadera en el 95 % de las muestras posibles.
¿Cómo achico el intervalo?
Aumentando el tamaño de la muestra o bajando el nivel de confianza.
¿Qué es el margen de error?
La mitad del ancho del intervalo: c·s/√n.
