Media aritmética, geométrica y armónica

"Promedio" no siempre significa sumar y dividir. Según lo que se quiera promediar (valores, tasas de crecimiento o velocidades), la media correcta es otra, y elegir mal da resultados engañosos.

Respuesta rápida

AM = Σx/n · GM = ⁿ√(Πx) · HM = n/Σ(1/x) · QM = √(Σx²/n) · HM ≤ GM ≤ AM ≤ QM.

¿Preferís que lo calcule por vos?

Abrir calculadora

1. Media aritmética

AM = (x₁ + x₂ + … + xₙ) / n

Es el promedio de todos los días: se suman los valores y se divide por la cantidad. Es la adecuada para magnitudes que se suman (notas, alturas, temperaturas).

2. Media geométrica

GM = ⁿ√(x₁ · x₂ · … · xₙ)

Se usa con factores que se multiplican: tasas de crecimiento, rendimientos, razones. Solo se define para números positivos.

  1. Una inversión rinde +10 %, +20 % y −5 % en tres períodos
  2. factores: 1,10 · 1,20 · 0,95 = 1,254
  3. GM = 1,254^(1/3) ≈ 1,0784 → crecimiento promedio de 7,84 % por período

La media aritmética de los factores (1,0833, es decir 8,33 %) sobreestima el crecimiento real.

  1. Una inversión sube 50 % y después baja 50 %
  2. la media aritmética de las variaciones es 0 %, pero 1,5 · 0,5 = 0,75: se perdió el 25 %
  3. GM = √0,75 ≈ 0,866 → −13,4 % por período

3. Media armónica

HM = n / (1/x₁ + 1/x₂ + … + 1/xₙ)

Es la correcta para promediar velocidades en tramos de igual distancia, o precios y rendimientos medidos "por unidad".

  1. Ida a 60 km/h y vuelta a 40 km/h (misma distancia)
  2. HM = 2 / (1/60 + 1/40) = 2 / 0,04167
  3. = 48 km/h (no 50 km/h)
  1. Se compran dólares con $1.000 cada mes: el primer mes a $900 y el segundo a $1.100
  2. precio promedio de compra = 2 / (1/900 + 1/1.100)
  3. = $990 (menor que el promedio simple de $1.000)

4. Media cuadrática

QM = √((x₁² + x₂² + … + xₙ²) / n)

Se usa en física e ingeniería: el valor eficaz (RMS) de una señal eléctrica es una media cuadrática, y la desviación estándar es la media cuadrática de los desvíos.

5. Cómo se relacionan

Para números positivos siempre se cumple:

HM ≤ GM ≤ AM ≤ QM

Las cuatro son iguales solo cuando todos los datos son iguales.

6. Errores comunes

  • Promediar velocidades o tasas con la media aritmética.
  • Calcular la media geométrica con ceros o negativos (no se define).
  • Promediar porcentajes directamente cuando las bases son distintas.
  • Creer que "el promedio" es una sola cosa: siempre conviene preguntarse qué se está promediando.

Ejercicios para practicar

Probá resolverlos vos y después abrí la solución para comparar.

  1. Calculá la media geométrica de 4 y 9.

    Ver la solución

    GM = √(4 · 9) = √36 = 6.

  2. Un auto va a 90 km/h y vuelve por el mismo camino a 60 km/h. ¿Cuál es su velocidad media?

    Ver la solución

    Es la media armónica: 2 / (1/90 + 1/60) = 72 km/h (no 75).

  3. Un capital crece 20 %, 20 % y −10 % en tres años. ¿Cuál es el crecimiento anual promedio?

    Ver la solución

    GM = (1,2 · 1,2 · 0,9)^(1/3) = 1,296^(1/3) ≈ 1,090: 9,0 % por año.

Preguntas frecuentes

¿Cuándo se usa la media geométrica?
Para tasas de crecimiento, rendimientos y razones: magnitudes que se multiplican entre sí.
¿Cuándo se usa la media armónica?
Para promediar velocidades en tramos de igual distancia y para precios o rendimientos por unidad.
¿Cuál es la mayor y cuál la menor de las medias?
Para números positivos: armónica ≤ geométrica ≤ aritmética ≤ cuadrática.
¿Cómo se calcula la media geométrica con calculadora?
Multiplicando todos los datos y sacando la raíz n-ésima, o con logaritmos: exp(promedio de los ln).
