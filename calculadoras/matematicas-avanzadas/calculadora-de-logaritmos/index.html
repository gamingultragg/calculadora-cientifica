Ayuda y Fórmulas Teóricas

Definición

log_b(x) = y  ⇔  bʸ = x

El logaritmo en base b de x es el exponente al que hay que elevar b para obtener x. Por ejemplo, log₂(8) = 3 porque 2³ = 8.

Cambio de base

log_b(x) = ln(x) / ln(b) = log(x) / log(b)

Permite calcular cualquier logaritmo con las teclas log o ln de una calculadora común.

Propiedades

log(a·b) = log a + log b  ·  log(a/b) = log a − log b  ·  log(aⁿ) = n·log a

El logaritmo solo existe para números positivos y la base tiene que ser positiva y distinta de 1.

Preguntas frecuentes

¿Qué es un logaritmo?
Es el exponente al que hay que elevar una base para obtener un número. log₁₀(1000) = 3 porque 10³ = 1000.
¿Cómo se calcula un logaritmo en cualquier base?
Con el cambio de base: log_b(x) = ln(x)/ln(b). Para log₃(81): ln 81 / ln 3 = 4.
¿Cuál es la diferencia entre log y ln?
log suele ser el logaritmo decimal (base 10) y ln el natural (base e ≈ 2,718). Se relacionan por ln(x) = 2,3026 · log(x).
¿Por qué no existe el logaritmo de 0 ni de un número negativo?
Porque ninguna potencia de una base positiva da 0 ni un resultado negativo.
¿Para qué se usan los logaritmos?
Para trabajar con escalas muy amplias: el pH, los decibeles, la escala de Richter y el interés compuesto, entre otros.
